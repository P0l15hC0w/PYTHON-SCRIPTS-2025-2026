# Models
 3D models provided are just a showcase of the app's work.

 Any 3D object with the .obj extension, following it's 'syntax' will work on the provided 3D renderer

 the renderer should be interpreted as a fun project.

# Performance notice
 This app should not be taken seriously as a whole 3D render program, but rather an 'experiment'

 The app itself is **UNOPTIMISED** and won't work well on bigger 3D objects.
