# USE OF PROJECT
this project uses both **nmap** and **scapy**.
which are crucial for it to function.

**to install both:**

- **nmap** - visit: <a style="color:white;">*npcap.com*</a> - download the latest installer.
- **scapy** - open up your CL and type '*pip install scapy*'.

**to install other modules:**

- **mac vendor lookup** - open up your CL and type '*pip install mac-vendor-lookup*'.

# USE OF TOOLS GIVEN

the app combines tools to create a **network discovery** script, which shall not be used to scan for networks.
